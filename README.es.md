# Physics × Software

[English](./README.md)

Portafolio interactivo de Física I enfocado en aplicaciones reales de la mecánica dentro de la ingeniería de software.

El proyecto desarrolla cinco temas mediante simulaciones, diagramas y visualización de datos:

- **Navegación de un dron de reparto** — Utiliza cinemática 2D para calcular posición, velocidad y aceleración durante una ruta simulada.
- **Salto de un personaje en videojuegos** — Muestra cómo el impulso de salto y la gravedad cambian la altura, el tiempo en el aire y la trayectoria.
- **Gravedad artificial por rotación** — Calcula la gravedad aparente generada por un hábitat rotatorio a partir del radio y las RPM.
- **Agarre de llantas de Fórmula 1** — Simula cómo la temperatura y la carga vertical afectan el agarre disponible del neumático.
- **Fuerzas en un control háptico** — Aplica la ley de Hooke para modelar la resistencia de un gatillo adaptativo virtual.
