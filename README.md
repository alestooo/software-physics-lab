# Physics × Software

[Español](./README.es.md)

An interactive Physics I portfolio focused on real applications of mechanics in software engineering.

The project explores five topics through interactive simulations, diagrams, and data visualization:

- **Delivery drone navigation** — Uses 2D kinematics to calculate position, velocity, and acceleration during a simulated route.
- **Character jumping in video games** — Shows how jump impulse and gravity change height, airtime, and trajectory.
- **Artificial gravity by rotation** — Calculates the apparent gravity generated by a rotating habitat using radius and RPM.
- **Formula 1 tire grip** — Simulates how temperature and vertical load affect the available tire grip.
- **Haptic controller forces** — Applies Hooke’s law to model the resistance of a virtual adaptive trigger.

## Built with

- Astro
- TypeScript
- CSS

- Interactive physics simulations
